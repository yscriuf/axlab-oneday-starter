# 00 · 환경 확인

**목표**: 이 프로젝트가 로컬에서 실행되는지 확인한다.

**진행 (네가 자동 실행)**
- `node -v`로 Node 설치 확인. 없으면 설치를 안내한다.
- `npm install` 실행.
- `npm run dev` 실행 후, 학생에게 http://localhost:3000 을 열어보라고 안내한다.

**학생이 직접 할 일**: 브라우저에서 http://localhost:3000 을 열어 Next.js 기본 화면이 보이는지 확인.

**완료 신호**: 학생이 로컬 화면이 뜬 걸 확인하고 "됐어/다음".
