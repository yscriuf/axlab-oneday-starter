# 02 · 소개 페이지 만들기

**목표**: `design.md`를 준비하고, 그걸 기준으로 서비스 소개 페이지(`app/page.tsx`)를 만든다.

**A. design.md 준비 — 학생이 직접 할 일 (hands-on)**
- refero(https://styles.refero.design/)에서 마음에 드는 디자인을 고르고, DESIGN.md의 **Extended 탭 → ⬇ .md** 버튼으로 파일을 다운받아 **이 폴더에 넣게** 안내한다.
- 파일이 들어오면 네가 읽어 프로젝트 루트에 `design.md`로 저장한다. (CLAUDE.md의 한글 규칙이 자동 적용된다 — 학생이 "참고해줘"라고 안 해도 됨.)

**B. 내용 정리 + 페이지 생성**
- 소개 페이지에 담을 헤드라인·기능·CTA를 학생에게 물어 정리한다.
- `design.md` + 그 내용으로 `app/page.tsx`를 만든다(네가 구현).

**학생이 직접 써보게 할 프롬프트 (B)**: 페이지에서 고치고 싶은 부분을 **학생이 직접 문장으로** 수정 요청하게 코칭한다(예: "헤더 여백 더 주고 폰트 키워줘").

**완료 신호**: 소개 페이지가 localhost에 뜨고 학생이 만족 + "됐어/다음".
