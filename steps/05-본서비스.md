# 05 · 본 서비스 만들기 (Phase 1)

**목표**: `service-prd.md`의 Phase 1(MVP)을 실제로 구현하고, 본 서비스를 재배포한다.

**진행**
- `service-prd.md`와 `design.md`를 기준으로 Phase 1 화면·핵심 기능을 네가 구현한다.
- 로컬(`npm run dev`)에서 확인하며 다듬는다.
- 오늘 범위(Phase 1) 밖 욕심은 "집에서 / 추후 과제(#extra)"로 안내한다.
- AI 기능을 쓰게 되면 **Gemini**로 만든다. 키 발급·저장 등 자세한 건 웹 교재 #extra 참고(CLAUDE.md 'AI 기능이 필요할 때' 규칙 적용).

**여러분이 직접 써보게 할 프롬프트**: 기능·화면 수정 요청을 **여러분이 직접 문장으로** 하도록 코칭한다.

**본 서비스 재배포 — 공개 전 민감정보 점검 (중요)**
Phase 1이 완성되면 본 서비스도 배포한다. 단, **배포하는 순간 URL을 아는 누구나 접근**할 수 있으므로 배포 전에 여러분에게 확인한다:
- 회사 내부 자료·고객 정보·개인정보 같은 **민감한 데이터가 들어있진 않은가?**
- 있으면: 배포 전에 비밀번호로 잠그거나 예시 데이터로 바꾼다(여러분이 원하면 네가 처리). 아니면 오늘은 로컬로만 보고 공개하지 않는다.
- 없으면(예시·더미 데이터뿐): 그대로 재배포한다.
점검을 통과하면 03단계와 같은 방식으로 재배포하고 URL을 확인한다.

**여러분이 직접 할 일**: 민감정보 여부 판단, 재배포 승인, 나온 URL 확인.

**완료 신호**: Phase 1이 동작하고, (배포했다면) 재배포 URL 확인 + 여러분 "됐어/다음".
