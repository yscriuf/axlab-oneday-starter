# 03 · 배포 — 첫 결과물

**목표**: 소개 페이지를 Vercel에 배포해 URL을 얻는다.

**진행**
- 웹 교재 #deploy의 현재 배포 절차(Vercel 계정 → 배포 토큰 발급 → Vercel CLI 설치·배포)를 따른다. CLI 설치·배포 명령은 네가 실행하되, **학생만 할 수 있는 것**(Vercel 로그인·토큰 발급·배포 승인)은 학생에게 시킨다.
- 배포되면 URL을 확인한다.
- (정확한 최신 토큰·명령 문구는 웹 교재 #deploy 기준. 계정/토큰 같은 민감정보는 학생이 직접 넣게 하고 절대 대신 입력하지 않는다.)

**학생이 직접 할 일**: Vercel 계정 준비·토큰 발급·배포 승인, 나온 URL을 브라우저로 확인.

**완료 신호**: 배포 URL이 나오고 학생이 확인 + "됐어/다음".

**PROGRESS 기록**: 배포 URL을 적는다.
